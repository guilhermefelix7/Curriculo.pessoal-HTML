# Portfólio Pessoal

## Sobre o projeto

Este projeto foi desenvolvido como uma atividade de HTML. 
A ideia foi criar uma página pessoal simples, contendo informações sobre mim, minhas habilidades, alguns projetos e uma área para contato.

## Tecnologias utilizadas

- HTML5

## Estrutura do site

O site possui:

- Cabeçalho com meu nome e profissão
- Menu com links para as seções da página
- Seção "Sobre Mim"
- Foto de perfil
- Lista de habilidades
- Tabela com meus projetos
- Formulário de contato
- Rodapé com e-mail e telefone

## Formulário

O formulário possui os seguintes campos:

- Nome
- E-mail
- Assunto
- Mensagem
- Botão de envio

## Objetivo

O objetivo da atividade foi praticar a criação de páginas HTML utilizando tags como:

- `<h1>` e `<h2>`
- `<p>`
- `<img>`
- `<ul>` e `<li>`
- `<table>`
- `<form>`
- `<fieldset>`
- `<input>`
- `<select>`
- `<textarea>`
- `<button>`
- `<footer>`
